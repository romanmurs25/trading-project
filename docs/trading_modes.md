# Торговые режимы

## RESEARCH

Режим по умолчанию. Используется для разработки, чтения конфигурации, тестов и аналитики. Реальные ордера
запрещены.

## PAPER

Исполнение идёт только через `PaperBroker`. Этот режим подходит для синтетических бэктестов и будущего
paper trading.

## SANDBOX

Зарезервирован для будущих брокерских песочниц. В первом MVP реальные SDK не подключаются.

## LIVE_READONLY

Будущий режим чтения live-аккаунта без размещения заявок.

## LIVE_GUARDED

Будущий режим live-исполнения. Даже в этом режиме ордер должен пройти все safety gates: явный флаг
`ALLOW_LIVE_TRADING=true`, поддержка адаптером, `RiskEngine`, `KillSwitch`, allowlist, свежие данные, спред,
idempotency key и audit-события.
